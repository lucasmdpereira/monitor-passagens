# Origem

Fork de [ManoelDiniz/monitor-passagens](https://github.com/ManoelDiniz/monitor-passagens), commit `2bc3243117f36ab93beeeb57119c16aaa286eaec`, avaliado em 24/11/2026.

Os adaptadores de Google Flights, Kiwi e MaxMilhas e o transporte HTTP derivam do projeto original. O histórico Git preserva a autoria. Esta versão remove painel, banco, notificações, agendador, câmbio, cripto e fontes que exigem credenciais, e acrescenta um contrato JSON para consultas nacionais.

O upstream não apresentou arquivo de licença nem campo `license` no pacote avaliado. Este fork não acrescenta uma licença sobre o código do autor nem afirma autorização adicional de distribuição fora do GitHub.

O catálogo de aeroportos vem do OurAirports, disponibilizado em domínio público. A URL, data de coleta e SHA-256 do arquivo de origem estão em `catalog/brazil-airports.json`. A indicação de serviço regular não comprova que uma companhia opera a rota ou data pesquisada.
